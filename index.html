TypeScript 実行環境

提出先として想定しているのは TypeScript 5.9 / tsc 5.9.2 / Node.js 22.19.0 です。

tsc Main.ts --target ESNext --moduleResolution nodenext --module NodeNext --noEmitOnError --pretty true → sh node.sh {memory:kb} Main.js ONLINE_JUDGE ATCODER

✓ 型チェック: TypeScript 5.9.2 のコンパイラAPIで、AtCoder と同じ target ESNext / moduleResolution NodeNext / module NodeNext / noEmitOnError を使って診断します。標準ライブラリは初回だけ CDN から読み込みます。Node 型は競プロでよく使う require/process/fs を中心にした軽量定義です。

▶ 実行: TypeScript 5.9.2 で同じ target/module/moduleResolution を指定して JavaScript に変換し、Web Worker 内で実行します。fs.readFileSync(0, "utf8")、process.stdout.write、console.log など競プロでよく使うAPIを簡易互換しています。

注意: Safari の中で本物の Node.js 22.19.0 を起動しているわけではありません。Node固有ライブラリ、ファイルアクセス、ネイティブ挙動、厳密な実行速度は AtCoder と異なります。

ソースは端末内に自動保存されます。全文コピーは CodeMirror の DOM を全選択せず、内部ドキュメント文字列を直接 Clipboard API に渡すため、1万行超でも軽く動作する設計です。

⌕ ソース内検索: 検索ボタンから検索欄を開き、次/前の一致箇所へ移動できます。

↺ リセット: 設定のテンプレートURLが空ならソースを全削除します。URLが設定されている場合はそのURLから最新版を取得します。取得成功時はURLごとの端末内キャッシュも更新し、通信失敗時は同じURLで最後に取得できた内容へフォールバックします。リセット直後は Undo で元の編集内容へ戻せます。
